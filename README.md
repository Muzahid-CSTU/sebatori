## SebaTori — Social Development Events Platform

SebaTori is a community-driven event management platform that connects people with social service activities in their local communities. Users can discover upcoming events, create events, join community initiatives, and manage their own activities.

## Key Features

User Authentication: Register and log in using Better Auth.

Social Login: Support for Google or GitHub login, depending on the configured provider.

Upcoming Events: Browse upcoming community service events.

Create Events: Authenticated users can create events with titles, descriptions, event types, locations, dates, and image URLs.

Join Events: Logged-in users can join events and avoid duplicate registrations.

Joined Events: View events joined by the currently logged-in user.

Manage Events: Update and delete events created by the authenticated user.

Protected APIs: JWT verification protects routes that require authentication.

Responsive Design: Interface designed for mobile, tablet, and desktop screens.

Dark and Light Themes: Switch between light and dark modes.

Loading States: Skeleton loaders improve the user experience while data is loading.

Community Gallery: Display community service activities and initiatives.
